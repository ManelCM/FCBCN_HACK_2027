Cómo reproducir la entrega

Cuatro pasos, el mismo fichero byte a byte

1

git clone --recursive <repo> ; cd <repo>

2

uv sync (Python 3.11, versiones fijadas en uv.lock)

3

datos del reto en data/ (o MTAH_DATA_DIR)

4

uv run python -m hackbarca.pipeline.make_submission --model l3 --team-name "La MasIA"

Salida

submissions/La MasIA.csv validado + su sha256 para comparar

Por qué es exacto

El modelo va versionado: la entrega no reentrena, solo predice

Antes del 14 nov

Otra persona lo prueba en un clon limpio: mismo sha256
